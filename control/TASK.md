# ClientOpsCRM 2.0.0 task

Evolve the verified ClientOps Relay 1.2.1 baseline into a complete operator-side CRM while preserving Relay as the deterministic intake and automation subsystem.

The CRM must be a real compiled C/C++ application and is CLI-only in this release. It must provide persistent organizations/accounts, contacts, leads, qualified opportunities/deals, configurable pipeline stages, tasks, notes, custom fields, search, duplicate detection, forecasting, dashboards, timelines, and audit history. Lead conversion must create/link the appropriate customer entities and opportunity in one transaction. Deal stage movement, win/loss, task completion, and all other state-changing commands must be validated and auditable.

The research program must study current top-tier CRM product primitives, official database/security standards, and high-grade academic/system sources, expanding the inherited Relay source register beyond 100 unique references. Research informs the feature set and invariants but does not copy proprietary code or UI.

The release must include source, build instructions, real tests, adversarial tests, API/CLI reference, architecture, data model, glossary, research synthesis, verification evidence, licensing, manifests, and packaging suitable for open-source release.
